三、如何查看 Git 历史
   在本文件夹中执行：

     git log --oneline --graph

   推荐看两处：

     git show 5eeb342     # 修复"重置按钮报错"的那次提交，diff 只有 5 行
     git show 37ab7bf     # 引入滑块、同时埋下那个 bug 的提交，可与上一条对照

五、验收提示（约 1 分钟）
   1. 打开页面，单摆应在深色背景中平滑摆动；
   2. 点击「月球」→ 重力数值在约 0.3 秒内平滑滑到 1.60，滑块同步跟随；
   3. 点击「重置摆动」→ 摆球回到 45° 初始位置（此处即当初报错的位置）；
   4. 拖动摆长到 300 后按 F5 刷新 → 参数与场景高亮应被完整恢复；
   5. 按 F12 打开控制台 → 全程应无任何红色报错。
